How do I submit a score?

You don't. {{ SITE_NAME }} reads the global osu!lazer score feed and automatically keeps every osu!catch score that used the Relax mod. New scores usually appear within a couple of minutes.

Where do the pp values come from?

There is no official Relax pp for osu!catch, so — exactly like Relaxation Vault does for osu!standard — {{ SITE_NAME }} computes the normal osu!catch pp for the Relax score, using rosu-pp. Current version: {{ pp_version }}. Player totals use the standard Σ pp × 0.95n weighting.
